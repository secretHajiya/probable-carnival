# Vyra Rewards — Test App

Complete Expo Android test project.
- Package: `com.vyra.rewards`
- Version: `1.0.1`
- Monetag Direct Link is included in `App.tsx`.
- This is a local/test rewards UI. Withdrawal is only recorded as a test alert; there is no real payment backend.

## Build

1. Upload the whole project to GitHub/Codemagic.
2. Make sure `codemagic.yaml` is at the project root.
3. Start the `vyra-apk` workflow.

Do not add `node_modules` to the repository.
